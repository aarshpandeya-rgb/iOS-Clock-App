# iOS Clock App

## Quick start
1. Create a new **iOS App** project in Xcode named `iOSClockApp`.
2. Choose **SwiftUI** and **Swift**.
3. Add the repository's `ClockApp.swift`, `Models`, `ViewModels`, `Utilities`, and `Views` files to the target.
4. Add the `UserNotifications` capability if alarm notifications are needed.
5. Build and run with `Cmd+R`.

> The repository contains source files; an `.xcodeproj` must be generated by Xcode to compile the app.
